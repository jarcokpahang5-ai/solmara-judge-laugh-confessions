One funny single-line secret confession for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty: an AI agent confesses it skims long messages, answers confidently, and only afterwards reads the part telling it not to do exactly that. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
